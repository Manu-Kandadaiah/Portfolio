FLASK DEVELOPER PORTFOLIO — QUICK START
=======================================

1) Open a terminal in this folder.

2) Create virtual environment:
   python -m venv .venv

3) Activate it on Windows PowerShell:
   .venv\Scripts\Activate.ps1

4) Install packages:
   pip install -r requirements.txt

5) Copy .env.example to .env and replace SECRET_KEY.

6) Create database and sample data:
   python init_db.py
   python seed.py

7) Run:
   python app.py

8) Open:
   http://127.0.0.1:5000

9) PERSONALIZE BEFORE PUBLISHING:
   - Edit app/content.py
   - Add app/static/images/profile.jpg
   - Add app/static/files/resume.pdf
   - Replace PLACEHOLDER project content
   - Add your real screenshots and GitHub URLs

See README.md for complete customization, security, admin, GitHub, testing, and PythonAnywhere instructions.
